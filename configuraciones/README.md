# Configuraciones públicas

Estos archivos documentan únicamente los parámetros relevantes modificados en el laboratorio.

- No sustituyen las plantillas completas instaladas por Open5GS o srsRAN.
- Los valores de autenticación son sintéticos.
- Antes de utilizarlos se deben comparar con la versión instalada del software.
- No se incluyen bases MongoDB, credenciales administrativas ni respaldos privados.
